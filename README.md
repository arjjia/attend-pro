# AttendPro MVP

Local-first PWA для криптографически проверяемой посещаемости. Преподаватель
показывает короткоживущий подписанный QR, устройство студента проверяет его и
подписывает собственную отметку. Отметку можно создать без сети и доставить на
портал позже.

Это новая принципиальная реализация утверждённой архитектуры: интерфейс написан
на `$mol`, локальное состояние хранится в IndexedDB, ключи создаются Web Crypto,
центральный журнал работает на FastAPI/PostgreSQL, а Giper Baza используется как
вторая local-first реплика доказательства. Старый React-код и схема с
шестизначными серверными кодами удалены.

## Запуск

Нужны Docker и Docker Compose v2.

```bash
cp .env.example .env
docker compose up --build
```

После запуска:

- приложение: <http://localhost:3000>;
- OpenAPI: <http://localhost:8000/docs>;
- healthcheck: <http://localhost:8000/health>.

В форме mock SSO доступны ровно четыре учётные записи:

- `teacher@attend.test` — преподаватель;
- `student1@attend.test`, `student2@attend.test`, `student3@attend.test` — студенты одной группы.

Пароль не нужен: mock SSO имитирует уже выполненную аутентификацию внешним
провайдером. Преподаватель может нажать «Запустить тестовую пару сейчас», создать
QR `ENTRY` или `EXIT`, а студент — отсканировать его либо вставить JSON из поля
под QR. Для проверки офлайна сначала один раз войдите каждым пользователем при
доступной сети, чтобы устройства получили сертификаты и доверенный открытый ключ
портала.


## Важная миграция

Ревизия `0002` заменяет прежнюю одноразовую схему прототипа на UUID/SSO и
подписанные доказательства. Старые тестовые пользователи и отметки намеренно не
переносятся: у integer-идентичностей нет достоверного соответствия новым SSO
subject. Для MVP это безопасное удаление fixtures; реальные данные перед такой
миграцией потребовали бы отдельной таблицы соответствий и backup.
